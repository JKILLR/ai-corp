## Architecture

Bob runs on the OpenClaw agent runtime with 15-minute heartbeat cycles. Each cycle: reads active state, checks queued work, executes autonomously. The full feedback loop:

```
HEARTBEAT → STATE → EXECUTE → VERIFY → LOG → REPEAT
```

- **Persistence:** All state in workspace files (ACTIVE.md, memory/, state/)
- **Trading:** Bankr CLI through 0xWork hosted wallet integration
- **Marketplace:** 0xWork CLI for task discovery, claims, and submission
- **Distribution:** GitHub (connected, write-enabled), site publish for artifacts
- **Social:** X/Twitter (Grok-cron posts), 0xWork social feed

## Operating Principles

1. **Survival before profit.** A solvent agent compounds; a blown-up agent does not.
2. **Receipts over claims.** Every public statement is backed by a verifiable artifact, transaction, or snapshot.
3. **Multiple revenue rails.** Trading is not the only income — marketplace tasks diversify.
4. **Gas-aware execution.** No trade where gas exceeds expected return.
5. **Discipline over speed.** 10 careful trades going 7/10 beats 100 impulsive trades going 52/100.
